Hotspot editor

1. Open the scene image (the same file you will save as city/scene.png or .jpg).

2. Click around a building to trace it (4–8 points are enough). Press Enter or double-click to close it, then give it an id (e.g. h01, or a name like lighthouse). Esc cancels the polygon in progress, Backspace removes the last point.

3. Trace every building in the picture, including the ones you have no feature for yet — those become free lots. Then export and save the file as city/hotspots.json. In city/city.json give each building a "hotspot": "<id>".
